# RAION Admin

RAION 확장프로그램 · 유벤져스 회원 관리 콘솔의 **진입 페이지**입니다.

관리자 전용입니다. 이 주소를 열면 로그인 화면만 나옵니다.

- 구글 로그인 또는 이메일/비밀번호로 인증
- 인증 후에도 `uvengers_members.role = 'admin'` 인 계정만 통과

접근 통제는 화면이 아니라 **데이터베이스**에서 이뤄집니다.
모든 테이블에 Row Level Security 가 걸려 있어, 화면을 우회해 API 를 직접 호출해도
관리자가 아니면 어떤 행도 반환되지 않습니다.

> 이 저장소에 담긴 키는 Supabase **anon(공개)** 키뿐입니다.
> 공개를 전제로 설계된 키이며, 실제 권한은 로그인 세션과 RLS 정책이 판정합니다.

## 유유스 학습실 탭 — 2026-09-09 연결 체크포인트

기존 탭은 유지하고 `유유스 학습실`을 추가했다. contract v2는 기수 생성/상태,
기수별 수강 명단 추가/취소, 일치 명단을 근거로 한 가입 승인, 현재 기수 배정,
학습실 이용 정지/해제와 변경 기록을 관리한다. 비밀번호·중앙 계정 삭제/정지·Editor
회원 테이블은 이 탭에서 다루지 않는다.

- API는 `academy_api` 하나이며 서버가 별도 academy staff·현재 세션·중앙 ban과 revision을 검사한다. 기존 `uvengers_members.role=admin` UI 통과만으로 새 권한이 생기지 않는다.
- 원문 데이터를 HTML로 넣지 않고 DOM/textContent로 표시한다. 15초 제한·중립적인 결과 미확인 안내·재조회·포커스 복원·계정 변경 시 데이터 폐기를 포함한다.
- 변경 전 확인 창과 사유를 요구한다. 학생에게는 기수 선택을 제공하지 않고, 이름·canonical
  Gmail·휴대폰 끝 4자리가 모두 같은 운영 명단 없이는 승인/기수 전환할 수 없다.
- 기수·명단·승인 작업은 중앙 계정/Editor 권한을 바꾸지 않는다. 사용자의 운영 결정에 따라
  이 탭은 별도 TOTP를 요구하지 않고 기존 RAION Admin 로그인과 명시적 academy staff 등록을
  모두 통과한 관리자만 사용한다.
- SQL 계약은 academy 저장소의 `database/academy/` 독립 체인이다. 기존 root Supabase migrations를 shared 프로젝트에 적용하지 않는다.
- 원격 DB/API 적용과 정확한 관리자 권한·기수 seed는 별도로 검증한다. 기존 페이지의 unsafe HTML 출력·정지 관리자 처리·원격 세션/경합·백업·기존 제품 회귀는 실제 수강생 데이터 투입 전 차단 항목이다.
- 관리자로 쓸 정확한 중앙 Auth UUID와 기수를 검증한 뒤 승인된 계정만 등록한다. 기존 관리자 전체에 학습실 권한을 자동 부여하지 않는다.

검사: `node --check academy-admin.js`, `node --test tests/academy-admin.test.cjs`, `git diff --check`. 로컬 예시 브라우저 375px/데스크톱·기수 미선택 오류를 확인했다. 실제 API나 이메일 테스트를 뜻하지 않는다.
